# 🏨 Hospitality Analysis – Power BI

## 📊 Project Overview

This project focuses on analyzing hotel booking data using **Microsoft Power BI**. The dashboard provides insights into hotel revenue, bookings, occupancy, cancellations, and other key business performance metrics.

## 🎯 Project Objectives

* Analyze hotel booking performance
* Track total revenue and bookings
* Analyze occupancy trends
* Understand cancellation and no-show rates
* Compare weekday and weekend performance
* Analyze revenue by hotel and category
* Identify weekly trends in revenue, bookings, and occupancy

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **SQL**
* **Excel**
* **Data Modeling**

## 🗂️ Data Model

The project uses a **Star Schema** consisting of:

### Fact Tables

* `fact_bookings`
* `fact_aggregated_bookings`

### Dimension Tables

* `dim_date`
* `dim_hotels`
* `dim_rooms`

## 📈 Key KPIs

* Total Revenue
* Total Bookings
* Occupancy %
* Cancellation Rate
* ADR (Average Daily Rate)
* RevPAR
* DSRN
* DBRN
* DURN

## 📊 Dashboard Analysis

The dashboard provides analysis of:

* Revenue trends
* Booking trends
* Occupancy trends
* Weekday vs Weekend performance

* Booking status analysis
* Weekly performance
